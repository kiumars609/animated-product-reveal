# 🎨 Animated Product Reveal | CSS & HTML

A modern, minimal, and visually engaging **product reveal animation** built entirely with **CSS & HTML**. Perfect for showcasing products, portfolio animations, or interactive UI demos.

---

## 🔥 Features

- **Smooth Keyframe Animations:** Clean, continuous transitions that grab attention.
- **Minimal & Modern UI:** Focused on content without unnecessary clutter.
- **Fully Responsive:** Works across devices and screen sizes.
- **Creative Shapes & Elements:** Unique animated elements for a dynamic experience.
- **No JavaScript Required:** Pure CSS & HTML for lightweight performance.

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Keyframes, Transforms, Flexbox)
- **Google Fonts:** Poppins & Lato
- **Font Awesome 5.15.4** for icons
